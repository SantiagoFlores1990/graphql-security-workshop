# GraphQL Security Workshop

## Descripción
Este proyecto es un taller práctico para aprender sobre seguridad en GraphQL. Aquí exploraremos las mejores prácticas, vulnerabilidades comunes y cómo proteger nuestras aplicaciones GraphQL.

## Requisitos Previos
- Node.js (versión 16 o superior)
- npm o yarn

## Instalación
1. Clona este repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   ```
2. Navega al directorio del proyecto:
   ```bash
   cd graphql-security-workshop
   ```
3. Instala las dependencias:
   ```bash
   npm install
   ```

## Uso
1. Inicia el servidor:
   ```bash
   npm start
   ```
2. Abre tu navegador y ve a `http://localhost:4000` para interactuar con el servidor GraphQL.

## Estructura del Proyecto
- `index.js`: Archivo principal del servidor.
- `package.json`: Contiene las dependencias y scripts del proyecto.
